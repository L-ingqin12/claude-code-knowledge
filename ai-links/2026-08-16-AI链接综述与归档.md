## 二、分主题逐条分析

### A. 编码 Agent 入门（收藏于 2026/05/05）

**2. Explore Claude Code** — 免费交互式 Claude Code 学习网站
- 定位：浏览器内通过模拟项目边做边学 Claude Code，约 11 堂课，免安装。
- 要点：覆盖 settings.json、CLAUDE.md、权限、hooks 等配置体系；互动练习式教学。
- 学习价值：★★★★☆ — 零门槛、沉浸式入门，适合 Claude Code 新手。
- 关联：Claude Code 官方文档、Agent 化编码实践。
- ⚠️ 调研环境直连该站被拦截，内容依据第三方介绍，请自行访问核实。

**3. GitHub Copilot CLI for Beginners** — GitHub 官方入门教程
- 定位：官方出品的 Copilot CLI 编号课程仓库（00-quick-start → 04-agents-custom-instructions）。
- 要点：系统讲解交互模式 vs 非交互模式及适用场景；覆盖自定义指令与 Agent 化用法；配套官方 Blog 与 Microsoft Learn。
- 学习价值：★★★★★ — 官方权威、结构清晰，是 Copilot CLI 的最佳学习起点。
- 关联：终端 AI 助手（gh copilot）、交互式 shell 工作流。

### B. Agent 技能生态（Skills）

**1. antigravity-awesome-skills** — Agentic Skills 巨型聚合库
- 定位：一键安装的 Agent 技能合集，汇集 1900+ 技能，约 30K stars。
- 要点：覆盖 Claude Code、Cursor、Codex CLI、Gemini CLI、Antigravity；提供安装器 CLI（npx）、bundles、workflows；迭代活跃（v13.3.0）；支持选择性安装。
- 学习价值：★★★★☆ — 技能生态全景图 + 开箱即用来源，但体量巨大需甄别。
- 关联：Claude Code skills、MCP 工具生态、编码代理配置。

**6. I Have ADHD** — 给编码 Agent「治疗多动症」的技能包
- 定位：用 SKILL.md 指令集约束 Agent：先答核心、禁绕弯、省略铺垫与道歉，约 5.2K stars。
- 要点：支持 Claude Code plugin、codex-plugin 等多种安装；中英文 README；针对输出冗长、跑题、重复解释、自作主张加戏。
- 学习价值：★★★★☆ — 代码极简，是「用系统提示词约束 Agent 行为」+ 插件打包的最佳入门样本。
- 关联：System Prompt 设计、Agent 输出质量控制、token 成本优化。

**14. Pretty-mermaid-skills** — 让 AI 输出专业 Mermaid 图表的 Skill
- 定位：单 SKILL.md，支持 SVG 与 ASCII 两种输出，被多个技能市场收录。
- 学习价值：★★★☆☆ — 轻量，适合学技能封装。
- 关联：Mermaid、mermaid-cli、SKILL.md 规范。

**15. diagram-design** — Claude Code 的 29 种编辑级专业图表技能库
- 定位：约 17.1K stars 的高星技能库，13→29 种图表类型。

- 关联：SVG 可视化、WCAG、Claude Skills —— 与本库 Excalidraw 规范互补，可借鉴其「设计规范文档化」思路。

### C. 编码 Agent 解剖（源码级理解）

**4. 《Pi 的设计艺术》** — 逐行解读 pi-mono 源码的在线技术书
- 定位：ZhangHanDong 著，副题「构建生产级 Coding Agent 的架构决策」，配套仓库 antinomie-lab/pi-book。
- 要点：代表性章节 ch01「不是又一个 LLM 包装器」、ch08「agentLoop—发动机只管转」、ch09「工具执行不是插件调用」、ch31「反主流选择背后的判断」；ch03 提供阅读地图。
- 学习价值：★★★★★ — 「把 Agent 拆解到原子级」，理解 Agent 内部机制的稀缺教材。
- 关联：Agent Loop、上下文工程、工具调用协议、subagent 架构。

**11. pi-from-scratch** — 约 600 行 TypeScript 从零还原 Pi 核心逻辑
- 定位：以最小代码复现编程智能体的核心循环：上下文管理、工具调用、代码编辑与任务执行。
- 要点：与 pi-textbook《动手学 Pi》、how-pi-agent-works 同属一个学习生态；适合整库通读与二次改造。
- 学习价值：★★★★☆ — 用最小实现拆解 agent 核心逻辑，比啃大型框架源码门槛低得多。
- 关联：Agent 主循环与工具协议、Claude Code/Pi 类工具逆向。

**5. Prime Agent** — 自改进 RLM 编码与研究 Agent
- 定位：Prime Intellect 开源，基于自研 RLM harness，让 Agent 在运行中自我改进自身脚手架。
- 要点：宣称 ARC-AGI-3 约 95.5% 高分、超人类专家基线，但被质疑评测不透明、代码膨胀、指标口径存疑；支持多模型 provider，本地/远程运行。
- 学习价值：★★★★☆ — 2026 年 RL+Agent「自改进」潮流的代表，成绩需批判看待。
- 关联：RL/RLHF、Agent 评测基准（ARC-AGI）、长时任务 Agent。

### E. LLM 推理与成本工程

**9. prompt-cache** — LLM 智能语义缓存库（Go）
- 定位：基于向量嵌入做语义级缓存而非精确字符串匹配，提供 Docker 镜像与 Go SDK。
- 要点：宣称降本最高 80%、命中亚毫秒级；可配置相似度阈值 + 「灰区」回退策略（相似度不明确时回退真实模型保质量）。
- 学习价值：★★★★☆ — 代码小而聚焦，适合通读理解语义缓存全链路（嵌入→相似度→阈值/回退）。
- 关联：GPTCache/Redis 语义缓存、Embedding 检索、LLM 成本治理（可联动 [[参考-Ark-Agent-Plan计费与配置]] 的降本思路）。

**12. time-to-first-token** — 10 周 × 每天 30 分钟 LLM 推理优化路线图
- 定位：覆盖 vLLM、SGLang、量化、投机解码、基准评测的实践型自学路线。
- 要点：以 TTFT 首字延迟指标为线索贯穿到工程闭环；源码阅读 + 压测 + 调优为主线；社区认可度高。
- 学习价值：★★★★★ — 稀缺的系统化推理优化学习路径，节奏可执行、主题覆盖完整。
- 关联：KV Cache 与 PagedAttention、TTFT/TPOT 指标、量化与投机解码。

## 三、综述：方向与趋势

### 3.1 两次收藏潮的对比

| 时间 | 数量 | 主题主线 | 心态 |
|---|---|---|---|
| 2026/05/05 | 3 | Claude/Copilot 生态入门（教程、技能聚合） | 「怎么上手 AI 编码 Agent」 |
| 2026/08/16 | 13 | 源码解剖、自建轮子、推理优化、Harness 生态、安全对抗 | 「怎么理解 Agent 内部、怎么自己造轮子、怎么省成本」 |

三个月间兴趣明显从**使用者视角**（教程、现成技能）转向**构建者视角**（解剖 Pi、自改进 Agent、TTFT 优化、自建 Skill）。

### 3.2 七条主线

1. **Agent Skills 技能工程**（#1/#6/#14/#15）：从「提示词工程」演进为可打包、可安装、可复用的技能资产；与本库 [[TYPORA-KB-Home]] 的 typora-activation skill 同构 —— 技能正成为个人 AI 资产的新形态。
2. **编码 Agent 解剖学**（#4/#11/#5）：以小见大读懂 agentLoop、工具协议、上下文工程；prime-agent 展示 RL「自改进」前沿（含评测争议）。
3. **DeepSeek Harness 生态**（#13/#16）：与当前工具链直接相关的一手实测材料。
4. **LLM 推理与成本工程**（#9/#12）：从「会用」到「会优化」的进阶线，TTFT 是工程化的好切入点。
5. **系统设计底座**（#10）：补齐分布式知识框架，支撑 Agent 系统化理解。
6. **AI 安全对抗**（#8）：内容溯源 vs 移除工具的攻防，兼有伦理边界。
7. （弱关联）**基础设施**（#7）：容器虚拟化演进，值得关注但动手价值暂低。
