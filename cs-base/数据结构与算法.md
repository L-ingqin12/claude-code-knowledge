## 一、复杂度速查

| 结构 | 访问 | 查找 | 插入/删除 | 备注 |
|------|------|------|-----------|------|
| 数组/vector | O(1) | O(n) | 尾插均摊 O(1) | 连续内存 cache 友好 |
| 链表 | O(n) | O(n) | 已知位置 O(1) | 慎用：cache 不友好 |
| 哈希表 | — | 均 O(1) | 均 O(1) | 最坏 O(n)（碰撞链）；扩容 rehash |
| 平衡树(RB/B+) | O(logn) | O(logn) | O(logn) | 有序遍历/范围查询 |
| 堆 | — | 峰 O(1) | O(logn) | TopK/优先队列 |
| Trie | — | O(L) | O(L) | 前缀检索（路由表/词表） |
| 跳表 | — | O(logn) | O(logn) | Redis ZSet 底层之一 |

排序：比较类下界 O(nlogn)；快排均 O(nlogn) 最坏 O(n²)（随机化枢轴防）；归并稳定；计数/基数非比较可到线性（整数域受限）。

## 二、结构要点

- **哈希**：负载因子触发扩容；开放寻址 vs 拉链（删除墓碑）；一致性哈希见 [[高并发系统设计]] §五
- **堆**：`sift_up/sift_down`；多路堆/对顶堆求中位数；索引堆支持改值
- **树**：BST 中序=有序；AVL 严格平衡 vs RB 宽松（插入少旋转）；B+ 树矮胖为磁盘页设计（数据库索引）
- **并查集**：路径压缩 + 按秩合并 → 近似 O(α(n))；连通性/最小生成树 Kruskal
- **图**：邻接表为主；BFS 无权最短路、DFS 时间戳（环检测/拓扑）、Dijkstra 非负权、Bellman-Ford 允负边、Floyd 全源 O(n³)

## 三、十大题型骨架（面试手撕向）

1. **双指针**：对撞（两数有序和）/ 快慢（环检测 Floyd 龟兔）
2. **滑动窗口**：不定长窗口 `while(违规) shrink`；模板 = 扩右缩左 + 状态计数
3. **二分**：左闭右开统一模板；二分答案（最大化最小值）→ check 函数单调
4. **前缀和/差分**：区间和 O(1)；差分还原区间批量加
5. **单调栈**：下一个更大元素 / 柱状图最大矩形（哨兵收尾）
6. **回溯**：子集/排列/组合去重三件套——排序、used 数组、`i > start && nums[i]==nums[i-1]` 剪枝
7. **DP**：状态定义→转移方程→初始化→遍历序；经典族：背包(0-1/完全)、LIS(O(nlogn) 贪心+二分)、LCS、编辑距离、区间 DP（石子合并）
8. **贪心**：局部最优可证全局（跳跃游戏/区间调度按右端点排序）
9. **位运算**：异或消重 / n&(n-1) 清最低位 / 位掩码枚举子集
10. **图遍历变形**：多源 BFS（腐烂橘子）/ 拓扑排序判环（课程表）

> [!tip] 工程映射
> 滑动窗口≈流式限流计数器；单调栈≈大文件扫描的括号配对校验；拓扑排序≈构建依赖 DAG（[[lognet-rootcause-multiagent-architecture]] 的因果边展开同构）。
