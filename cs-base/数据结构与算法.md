## 一、复杂度速查

| 结构 | 访问 | 查找 | 插入/删除 | 备注 |
|------|------|------|-----------|------|
| 数组/vector | O(1) | O(n) | 尾插均摊 O(1) | 连续内存 cache 友好 |
| 链表 | O(n) | O(n) | 已知位置 O(1) | 慎用：cache 不友好 |
| 哈希表 | — | 均 O(1) | 均 O(1) | 最坏 O(n)（碰撞链）；扩容 rehash |
| 平衡树(RB/B+) | O(logn) | O(logn) | O(logn) | 有序遍历/范围查询 |
| 堆 | — | 峰 O(1) | O(logn) | TopK/优先队列 |
| Trie | — | O(L) | O(L) | 前缀检索（路由表/词表） |
| 跳表 | — | O(logn) | O(logn) | Redis ZSet 底层之一 |

排序：比较类下界 O(nlogn)；快排均 O(nlogn) 最坏 O(n²)（随机化枢轴防）；归并稳定；计数/基数非比较可到线性（整数域受限）。

## 二、结构要点

- **哈希**：负载因子触发扩容；开放寻址 vs 拉链（删除墓碑）；一致性哈希见 [[高并发系统设计]] §五
- **堆**：`sift_up/sift_down`；多路堆/对顶堆求中位数；索引堆支持改值
- **树**：BST 中序=有序；AVL 严格平衡 vs RB 宽松（插入少旋转）；B+ 树矮胖为磁盘页设计（数据库索引）
- **并查集**：路径压缩 + 按秩合并 → 近似 O(α(n))；连通性/最小生成树 Kruskal
- **图**：邻接表为主；BFS 无权最短路、DFS 时间戳（环检测/拓扑）、Dijkstra 非负权、Bellman-Ford 允负边、Floyd 全源 O(n³)

## 三、十大题型骨架（面试手撕向）

1. **双指针**：对撞（两数有序和）/ 快慢（环检测 Floyd 龟兔）
2. **滑动窗口**：不定长窗口 `while(违规) shrink`；模板 = 扩右缩左 + 状态计数
3. **二分**：左闭右开统一模板；二分答案（最大化最小值）→ check 函数单调
4. **前缀和/差分**：区间和 O(1)；差分还原区间批量加
5. **单调栈**：下一个更大元素 / 柱状图最大矩形（哨兵收尾）
6. **回溯**：子集/排列/组合去重三件套——排序、used 数组、`i > start && nums[i]==nums[i-1]` 剪枝
7. **DP**：状态定义→转移方程→初始化→遍历序；经典族：背包(0-1/完全)、LIS(O(nlogn) 贪心+二分)、LCS、编辑距离、区间 DP（石子合并）
8. **贪心**：局部最优可证全局（跳跃游戏/区间调度按右端点排序）
9. **位运算**：异或消重 / n&(n-1) 清最低位 / 位掩码枚举子集
10. **图遍历变形**：多源 BFS（腐烂橘子）/ 拓扑排序判环（课程表）

> [!tip] 工程映射
> 滑动窗口≈流式限流计数器；单调栈≈大文件扫描的括号配对校验；拓扑排序≈构建依赖 DAG（[[lognet-rootcause-multiagent-architecture]] 的因果边展开同构）。

## 三·补、题型走读（代码级：不变量与手推过程）

### 走读 1：二分查找——模板与不变量证明

```cpp
// 左闭右开 [lo, hi): 返回第一个 >= target 的下标(即 lower_bound)
int lower_bound(vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;   // 防溢出写法
        if (a[mid] < target) lo = mid + 1;
        else                 hi = mid;      // a[mid]>=target: 答案可能是 mid, 不能丢
    }
    return lo;   // lo == hi == 第一个不小于 target 的位置
}
```

**为什么它对（循环不变量）**：全程维持 `答案 ∈ [lo, hi)`。每次分支要么排除"确定 < target"的左半（`lo=mid+1`），要么保留 mid 为候选收缩右界（`hi=mid`）——两支都不破坏不变量；`lo<hi` 终止时区间恰含一个候选位。**背这个推导，所有二分变形（旋转数组/二分答案）都只是换判定条件**。常见死法对照：`hi=a.size()-1` 配 `lo<=hi` 是另一套闭区间模板，两套混用必死循环——**一套用到底**。

### 走读 2：编辑距离——DP 表逐行手推

`s="horse", t="ros"`，定义 `dp[i][j]` = s 前 i 个 → t 前 j 个的最少操作。

```
        ""   r   o   s
   ""    0   1   2   3          ← 边界: 全删/全插
   h     1   1   2   3          ← h≠r: min(删1, 插1, 替1+dp[0][0]=1)=1
   o     2   2   1   2          ← o==r? 否; o 对上 t[1]=o: dp[1][1]+0? 看 j-1 对齐
   r     3   2   2   2
   s     4   3   3   2          ← 答案 dp[5][3]=... 实际 horse→ros=3
```

转移方程三来源：`dp[i][j] = min(dp[i-1][j]+1(删), dp[i][j-1]+1(插), dp[i-1][j-1] + (s[i]!=t[j]))`。
**读表方法**：每个格子只依赖左、上、左上三个邻居——所以可以滚动数组压到 O(min(m,n)) 内存；这也是"DP 表就是 DAG 拓扑序"的具体体现（[[计算机组成原理]] 局部性视角：按行遍历对 cache 友好）。回溯路径从右下角沿"来自哪个邻居"反推即得操作序列。

### 走读 3：单调栈——柱状图最大矩形的完整 trace

问题： heights=[2,1,5,6,2,3]，求最大矩形面积。

```cpp
stack<int> st;  int ans = 0;
for (int i = 0; i <= n; ++i) {
    int h = (i == n) ? 0 : heights[i];       // 哨兵 0: 强制清空栈内全部待结算者
    while (!st.empty() && heights[st.top()] >= h) {
        int height = heights[st.top()]; st.pop();
        int left = st.empty() ? -1 : st.top();           // 左边界(不含)
        ans = max(ans, height * (i - left - 1));         // 宽 = i-left-1
    }
    st.push(i);
}
```

**逐事件 trace**（关键在"出栈即结算"语义——弹出时，其高度能延伸的左右边界同时确定）：

| i | 入高 | 动作 | 结算 |
|---|------|------|------|
| 0 | 2 | 栈[0] | — |
| 1 | 1 | 弹0(2≥1)：left=-1，宽=1-(-1)-1=1 → **面积2**；栈[1] | 2 |
| 2 | 5 | 栈[1,2] | — |
| 3 | 6 | 栈[1,2,3] | — |
| 4 | 2 | 弹3(6≥2)：left=2，宽=4-2-1=1→**6**；弹2(5≥2)：left=1，宽=4-1-1=2→**10**；栈[1,4] | 10 ✓ |
| 5 | 3 | 栈[1,4,5] | — |
| 6 | 哨兵0 | 弹5→3×1=3；弹4→2×4=8；弹1→1×6=6 | max 保持 10 |

**推理链**：栈内下标对应高度单调递增 ⇒ 当新元素更矮时，栈顶元素的矩形"右墙"确定=i，"左墙"=新的栈顶（更高的都被弹了），宽即 `(i-left-1)`。哨兵把结算逻辑统一到主循环免收尾特判——这是模板比直觉版短的根源。

### 走读 4：手写实现坑位清单（C/C++ 裸写版）

| 结构 | 必踩坑 → 正解 |
|------|--------------|
| 环形队列(顺序表) | head==tail 无法区分空/满 → **牺牲一格** 或维护 size 计数；取模容量用 2^n 位运算 |
| 链表删除 | 头节点特判地狱 → **虚拟头节点**统一；双指针找中点/判环(fast 走2 slow 走1, 相遇即环) |
| 栈表达式求值 | 运算符优先级两栈法：数字栈+运算符栈，入栈前弹光"≥当前优先级"；括号当优先级天花板 |
| 哈希表(开放定址) | **删除不能置空**——会截断探测链 → 惰性墓碑标记 + 负载含墓碑计数触发重建 |
| BST | 有序插入退化成链 → 删除双孩节点用**后继值替换再删后继**(转化成单孩问题)；AVL 只需记 balance factor 四种旋转 |
| 快排两种 partition | Hoare 双向扫(交换后指针相遇) vs Lomuto 单向扫(基准换尾)；Lomuto 全相同元素退化 O(n²) → 三路划分(< = >)治重复 |
| 归并排序 | merge 辅助数组每层 new=灾难 → 只分配一个全局缓冲来回倒；链表版 O(1) 空间且是**链表排序标准答案**(数组版快排胜在 cache) |
| 计数/基数排序 | 非比较排序的边界：值域大就炸内存(计数)；基数排序 LSD 按"个→高"多轮**必须稳定排序**(否则轮间次序被毁)，桶内用计数排序 |
