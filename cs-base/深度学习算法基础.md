# 深度学习算法基础

> [!abstract] 定位
> DL 算法主干：从 MLP 到 Transformer 的最小知识链 + 训练稳定性要点。数学手推与 MoE/MLA 等进阶结构在 [[AI大模型开发]]；训练工程化（LoRA/RAG/推理量化）分别在 [[LoRA参数高效微调实战]] / [[RAG检索增强生成实战]] / [[LLM推理部署与量化]]。

See also: [[CS-KB-Home]] · [[AI大模型开发]] · [[数据结构与算法]] · [[微调数据工程与模型蒸馏]]

## 一、最小知识链

```
线性回归 → 逻辑回归(sigmoid+BCE) → MLP(隐藏层+非线性) → CNN(权共享/池化)
        → RNN/LSTM(序列状态) → Attention → Transformer(自注意力堆叠)
```

| 组件 | 解决什么 | 关键公式/事实 |
|------|---------|--------------|
| 激活函数 | 引入非线性 | ReLU 族缓解梯度消失；GELU/SwiGLU 为 LLM 主流 |
| 损失 | 度量差距 | CE=softmax+NLL；回归 MSE/Huber |
| 反向传播 | 链式法则算梯度 | 计算图拓扑序反推；梯度检查用数值微分验证 |
| 优化器 | 更新参数 | SGD+动量→Adam(自适应二矩)；**AdamW** 解耦权重衰减为 LLM 默认 |
| 正则化 | 抗过拟合 | Dropout(p 训练开推理关)/权重衰减/早停/数据增广 |

## 二、归一化三兄弟

| 方法 | 归一维度 | 场景 |
|------|---------|------|
| BatchNorm | batch 维 | CV CNN 主力；小 batch/序列不稳 |
| LayerNorm | 特征维 | 序列模型标配（不依赖 batch） |
| RMSNorm | LN 去均值化简化版 | LLaMA 系采用，省算力 |

## 三、Transformer 最小集

1. **自注意力**：`softmax(QKᵀ/√d_k)V`；√d_k 防点积过大 softmax 饱和；多头=并行子空间
2. **因果掩码**：解码端上三角 -inf，位置 i 只见 ≤i
3. **位置编码**：正弦绝对式 → RoPE 旋转式（外推友好）→ ALiBi 线性偏置（各家选择不同）
4. **结构**：Pre-LN（稳定，现代默认）vs Post-LN（原始论文）；FFN 通常 4×d 隐层，SwiGLU 变体约 8/3×d×2 平衡参数
5. **复杂度**：注意力 O(n²·d)；长上下文优化方向 FlashAttention(IO 感知精确算子)/GQA/MLA（后者详见 [[AI大模型开发]] KV 缓存节）

## 四、训练稳定性速查（炼丹排障表）

| 症状 | 常见原因 | 处置 |
|------|---------|------|
| loss=NaN | lr 过大 / 数值溢出 | warmup + grad clip(norm 1.0) / fp32 累加 |
| loss 不降 | 数据管线 bug / 标签错位 | 先过拟合 10 条样本再谈调参 |
| 训练好验证差 | 过拟合 | 增强/正则/更多数据；查泄漏 |
| 收敛震荡 | batch 过小 / lr 调度陡 | 余弦退火 + 线性 warmup |

混合精度：fp16 需 GradScaler 防 underflow；bf16 指数位同 fp32 免 scaler（硬件支持为前提）。分布式并行五件套 DP/ZeRO/TP/PP/EP 对照见 [[LLM推理部署与量化]] 与 [[强化学习对齐-RLHF到GRPO]] 的训练侧。

## 五、待确认项

> ① 各家位置编码在 >128K 外推的公开对比数据口径不一；② Muon 等新优化器的复现结论尚在社区验证期；③ MoE 路由负载均衡 aux-loss 权重最佳实践无统一结论。
